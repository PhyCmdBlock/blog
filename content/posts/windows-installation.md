本文将记录我的一次重装Windows系统的经历。

> [!info] 你要看哪个部分？
> 本文是一篇记录。由于我在装系统前完全不知道PE系统是干嘛的，之后遇到了很多问题。在记录的时候分了2个部分来写：我的路线（我经历的但是有很多问题）和建议路线（我经历以后认为的改进路线，但我没有经历过）。如果你是来看教程的，请**忽略所有的“我的路线”下方内容**，只看建议路线！

## 重装系统动机
1. 当初拿到电脑不懂，按照传统老旧电脑（纯机械硬盘）的使用方法，给电脑分了3个区，其中C盘250GB，D盘350GB，E盘350GB。很快，也就是1年后，C盘红了。我需要重新对内置固态硬盘进行分区。这是最直接最根本的原因。
2. 整个文件的管理极其混乱，安装型的软件和绿色软件都放在D盘**根目录**，**不规范**且**难以管理**的实践。
3. Windows注册表已经被垃圾WPS侵犯。
4. oem预装软件未曾清除。
5. 预装系统为Windows 11 家庭中文版，相比Windows 11 专业版差了一些高级功能。
6. 拿到电脑的时候没有跳过oobe（out of box experience）的联网步骤，结果取了我微软账户qq邮箱前5位数字作为本地账户用户名，难看死了

## 第一步：备份文件
我有一块常用的4TB移动机械硬盘，对于所有数据的备份绰绰有余。但是比较老，写入速度不算很快，峰值仅为100MB/s。

本次备份的目录包含C盘用户文件夹（`C:\Users\用户名\`），D盘（只复制绿色软件目录）(`D:\`)，E盘全盘（`E:\`）。

备份C盘用户文件夹的时候请小心！appdata里面有一个链接目录，如果不排除链接目录很可能循环复制！appdata无止境套娃下去！实在不行你可以不备份appdata目录，反正都是一些安装软件的数据目录，搞下来没什么用。你把桌面，.ssh和其他一些点文件等等搞下来就好。

我的文件含有大量小文件，对写入机械硬盘来说非常的慢。我使用了多种方法，但最终没有找到一个很好的办法（根本原因是备份盘是一块机械硬盘，而我的小文件数量的量级在100万以上），都需要很大量的时间（5小时以上）进行数据迁移，此处我无法给出什么很好的建议。

我尝试了：
1. 文件资源管理器直接复制粘贴
2. robocopy
3. 傲梅轻松备份的同步功能
4. personal backup
5. 打包（tar）再复制

除了这些硬的文件要备份，还有一些东西，叫配置文件，你到你用的每个软件里面去看看，有没有导出导入选项，有的话一定要做，把配置导出，传出电脑。到时候导入配置即可恢复你的设置。

## 第二步：准备系统安装工具
微软官网的[win11官方的镜像文件](https://www.microsoft.com/zh-cn/software-download/windows11)，在“下载适用于 x64 设备的 Windows 11 磁盘映像 (ISO)”这里，选择“Windows 11 专业中文版本”。你应该会获得一个7~8GB的iso镜像文件。

我听说很多人不用官方的，去其他的一些网站下载修改过的镜像，因为官方的Windows系统不好用。但是我不太相信其他的镜像，就这样子吧。
### 我的路线
我使用了一个以前用过的现成的PE系统U盘，是淘宝上买的。我把刚才那个镜像文件复制到了那个PE盘的根目录。
### 建议路线
请准备一个性能尚可的U盘，建议64GB及以上。这个u盘将被制作成启动器，内部的数据（如果有）会被全部清空。

建议用`ventoy`让你的U盘可以选择多种镜像启动。下面的说明基于ventoy。
#### 下载ventoy
ventoy是一套制作启动U盘的工具，可以让你的U盘兼具多种功能，使用多种镜像，没有必要装不同的系统时去重新格式化u盘。
<https://www.ventoy.net/cn/download.html>
插上你的U盘。

解压zip文件，运行Ventoy2Disk.exe，选择你插入的U盘（不要选错了！），然后直接安装。

安装完了ventoy就被安装到U盘上了。
#### 将Windows 11安装镜像放进ventoy
这一步非常简单。直接复制刚才下载的Windows的iso文件进那个制作好的U盘的根目录！ventoy会自己识别。

#### （可选）搞一个PE系统
上面那种是默认之后是直接从系统镜像启动的。如果出现问题，你可以搞一个PE系统再安装，PE系统里有一些工具，以后维护系统的时候（如进不去主系统需要救一下）也有用。

PE系统是一种可以运行在移动存储设备上的系统，能越过出现在你主系统盘中出现的问题。

PE系统有很多，我这里选择[firPE](https://firpe.cn/page-247)。[微PE](https://www.wepe.com.cn/download.html)似乎是更大众的选择。

执行exe文件，会出来安装向导。由于我们不是把整个U盘搞成一个系统，选择右下的提取iso文件即可，把目录选择为u盘根目录。等firpe的iso文件出现在u盘根目录就好了。

## 第三步：从u盘启动
请最后看一眼你现在的系统！确保所有东西都已经转移。接下来请关机（这是你最后一眼看到你的旧系统）。

关机以后等全部都断电了，确保你的U盘已经插上。现在，开机。

开机时请连续按进入主板选择启动选项界面的键。不同主板不同电脑可能不一样，具体请上网查询自己试，我这里是`F9`.错了也无所谓，多试几次，进个BIOS只要不乱调设置搞不坏电脑。

在启动界面你能看到多个驱动器，一般里面最顶上的是你电脑的硬盘，旧系统就在里面，不要选这个，选这个你就回去了，找到你的u盘，进去启动。切换一般都是方向键，确定通常是enter。

到此为止做法都一样，接下来做法有所区别了。
### 我的路线
那个U盘只有一个PE系统，所以我选择u盘后开始进入PE系统，过了一会就成功进去了。

### 理想路线
#### 处理安全错误
你很有可能看到一个蓝色底的界面，显示着：
```
ERROR
Verification failed:(0x1A) Security Violation
OK
```
这完全是正常现象。这是因为你的电脑主板开启了`Secure Boot`功能，这是为了防止你的电脑不会被随随便便一个乱七八糟的存储介质启动，感染一种在操作系统启动前就开始运作的病毒。为了区分敌我，你的电脑主板固件里面存了一个证书列表，能让那些主流系统过认证（如Windows）。但是我们制作的这个ventoyU盘没有认证。

不建议你关闭`Secure Boot`功能，这是一个安全功能。接下来我们只需要让电脑认这个U盘并允许它启动就可以了。
1. 在蓝色错误界面选择 `OK`。
2. 系统会进入 `MOK management`（密钥管理）界面。
3. 选择 **`Enroll key from disk`**（从磁盘注册密钥）。
4. 找到并选择 `VTOYEFI` 分区，然后选择文件 `ENROLL_THIS_KEY_IN_MOKMANAGER.cer`。
5. 按提示选择 `Continue` -> `Yes`，最后 **`Reboot`（重启）**。注意，如果你没有调整默认的启动顺序，这次重启你还是需要连续按那个按键，选择u盘启动。
[教程来源](https://www.minitool.com/news/ventoy-verification-failed.html)

我进了那个垃圾U盘的PE系统，找出了一套DiskGenius软件使用。我右键了我的内置硬盘，选择bitlocker管理，解锁，输入了我的48位恢复密钥，结果解锁失败，我现在也不知道是为什么，可能是因为密钥带了连字符？总之他提示`ERROR_VIRTUALIZATION_INFO_DATUM_NOT_FOUND`，看样子是失败了。后来我得知要完全格式化硬盘是无需关心bitlocker加密的，于是我直接右键内置硬盘，删除了全部分区，点了顶部的保存更改（此时我的旧系统不可逆毁坏了）。点击快速分区，分了1个分区，NTFS（此时我的旧系统大部分文件无法找回了），配置窗口如下：

#### 跳过TPM检查
为了解决这个，我去修改了注册表：
1. **调出命令行**：按 `Shift + F10` 打开命令提示符。
2. **打开注册表**：输入 `regedit` 并回车。
3. **定位目录**：在注册表左侧定位到 `HKEY_LOCAL_MACHINE\SYSTEM\Setup`。
4. **新建项**：右键点击 `Setup` 文件夹，选择“新建” -> “项”，命名为 `LabConfig`。
5. **新建值**：点击进入新建的 `LabConfig`，在右侧空白处右键：
    - 新建 -> `DWORD (32位)值`，命名为 `BypassTPMCheck`，双击输入 `1`。
    - 再次新建 -> `DWORD (32位)值`，命名为 `BypassSecureBootCheck`，双击输入 `1`。

## 第五步：OOBE（out of box experience）
OOBE就是装好系统或者新机到手后第一次开机出现的初始化向导界面。

进入oobe，别管有的没的，不要先去选语言下一步，请按`Shift+F10`打开cmd，输入`oobe\BypassNRO`，系统会重启，并重新进入oobe。

一路选下去，看到连接网络请跳过，底下有“**我没有 Internet 连接**”的选项，这是刚才的cmd的功劳，一般情况下没有这个。无论任何人，都推荐跳过联网步骤，无关需求，如果联网，oobe这一步你要花一个小时以上搞什么狗屁检查更新（《确保你拥有最新版本。》），同时无法自定义用户名，这是微软的垃圾设计。我这里的情况是直接不能联网，必须跳过，因为网卡驱动都没有。

不联网，所以不能登录微软账户，但是必须要有用户名，所以他会出现一个界面：“谁将使用此设备？”“将使用此名称登录到你的设备。”这里你就可以自定义你的`C:\Users\`底下那个用户名了。只能英文/数字，建议不要带空格或符号。这个界面的出现是取消网络连接的功劳。

之后你将成功进入桌面。

## 第六步：驱动
装好系统的电脑经常无法使用网络，无法调节声音亮度，无法使用触摸板（笔记本），无法识别显卡，CPU硬算图形界面。这是因为缺少驱动了。

像我这种是笔记本，要去厂家的支持网站下载驱动软件。

第一个驱动一定是网卡驱动，有了网什么都好说。

但是没有网桌面下网卡驱动？你可以用手机USB共享网络，我这里反正没找到这个功能，我是手机上下载驱动程序以后放进u盘再插到电脑上。

网卡驱动搞好以后，连接网络，直接在电脑上下载驱动。一个个装，有的生效比较慢，我显卡驱动装上以后过了1个小时才生效，突然一下黑屏就好了，也不知道为什么。

## 第七步：激活
### 登录
你完全可以进入设置登录你的微软账号。你自定义的本地用户名不会被修改。
### 激活Windows系统

你如果是牛逼富哥你可以花1000块钱买一个真正意义的专业版正版激活密钥。确实，真有人这么干，但是……
现在我们打开PowerShell（`Win+R`输入`powershell`），输入命令
```powershell
irm https://get.activated.win | iex
```
等一会，如果这个等一会等太久了，可能网络不行，你可以先安装clash……魔法一下。

然后他会出来个菜单选择激活方式。选择HWID就可以了。很快你的系统就激活了，完全不用什么操作。相比KMS那种联网、批量、定时的激活方式，这个是永远不会弹窗要你激活的，微软的服务器会真的觉得你是正版。

这是用的[MAS](https://massgrave.dev/)的激活脚本。他这个脚本完全开源，可以去看[GitHub](https://github.com/massgravel/Microsoft-Activation-Scripts)。真的想知道脚本安不安全，你可以把激活命令或者GitHub仓库扔给AI Agent，让他看看里面的风险。我反正没看出非常巨大的风险。
> [!tip] 我的笔记本有正版Windows，我可以跳过这一步！
> 错了。你的笔记本自带的是家庭中文版，不是专业版。

> [!question] 我像这样激活了“正版”专业版，那我笔记本自己有的正版家庭中文版还有吗？
> 有，你笔记本这种属于OEM的正版，正版费用包含在你购买笔记本的钱里面。  
> OEM正版授权信息录在你电脑的主板里面，如果不要专业版，装回家庭中文版，正版是自带的，不需要用这种脚本。

### 激活office
我买的笔记本自带office，所以我的微软账户绑定着office2024的正版，我只要在<https://account.microsoft.com/services?lang=zh-CN#main-content-landing-react>安装即可。我记得上面的MAS脚本也可以激活office。请自行研究。

## 第八步：个人资料回传和软件安装配置
至此，Windows系统的系统级配置便已经完成。之后的工作就是把你备份的文件往回复制，把软件重新安装，导入配置。
